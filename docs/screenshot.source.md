# Скриншот интерфейса

Снимок работающего приложения из изолированной проверочной копии, 13–14 ноября 2026 года. Данные заявок и документов вымышленные; товары с меткой «Демо» используют подготовленные цены. В мониторинге строка Pimoroni получена из открытого источника во время проверки; значение на скриншоте не является обещанием текущей цены. Чужие изображения и макеты в снимок не добавлялись.

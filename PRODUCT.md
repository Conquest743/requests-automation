# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Node.js 22+, встроенный HTTP, HTML/CSS/JavaScript, JSON на диске; без npm-зависимостей. Manrope поставляется локально.

## Users
Человек разбирает входящие заявки; работодатель проверяет проект портфолио на своём компьютере.

## Product Purpose
Принять заявку, нормализовать контакт, отсеять повтор, определить приоритет по явным правилам и сохранить её в рабочую очередь.

## Operating Context
Windows, start.bat, адрес 127.0.0.1:4191. Интернет и аккаунты не нужны. Данные в data/ внутри проекта.

## Capabilities and Constraints
Импорт списка из JSON с отчётом по строкам, демонстрационный файл, ручная форма, поиск и фильтры, три статуса, история, CSV. Поддерживаются локальные файлы до 200 КБ и 100 записей. Нет почты, CRM, отправки сообщений, нейросетевой оценки или расписания. Один пользователь и один процесс на хранилище.

## Evidence on Hand
Исходная обработка portfolio/engine.js. Автономный проект в этой папке. Корневой PLAN.md ведёт состояние общей работы.
